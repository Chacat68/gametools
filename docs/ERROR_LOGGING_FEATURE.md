## 📝 新增功能：错误日志追踪

### 功能概述

表字段导出工具现在支持完整的错误和警告日志记录功能，能够帮助用户快速定位和解决提取过程中的问题。

---

## ⚠️ 日志类型

### 1. 错误日志 (Error Logs)
记录导致提取失败的严重错误，例如：
- 文件读取失败
- 工作表访问错误
- 权限问题

**格式示例：**
```
❌ 读取文件失败 | 文件: example.xlsx | 错误: Permission denied
```

### 2. 警告日志 (Warning Logs)
记录不影响提取但需要注意的问题，例如：
- **`FIELD_TYPE_ROW`（默认第 6 行）** 示例数据为空
- 表格行数不足以容纳字段类型行
- 数据格式异常

**格式示例：**（行号以默认 `FIELD_TYPE_ROW` / `FIELD_NAME_ROW` 为例，见 [EXCEL_TABLE_LAYOUT.md](EXCEL_TABLE_LAYOUT.md)）
```
⚠️ 示例数据为空 | 文件: config.xlsx | 工作表: 关卡配置 | 字段: level_name | 位置: 第6行,第3列(C6)
```

## 🖥️ GUI 界面使用

### 查看错误日志按钮

在字段导出界面，新增了 **"⚠️ 错误日志"** 按钮：

1. **独立GUI**: 位于主界面按钮区域
2. **统一GUI**: 位于"表字段导出"标签页的按钮区域

### 日志查看窗口

点击"查看错误日志"按钮后，会弹出日志查看窗口，包含两个标签页：

#### 📛 错误日志标签页
- 显示所有严重错误
- 标题显示错误数量：`错误日志 (X)`
- 每条错误包含详细信息

#### ⚠️ 警告日志标签页
- 显示所有警告信息
- 标题显示警告数量：`警告日志 (X)`
- 每条警告包含完整的定位信息：
  - 文件名
  - 工作表名
  - 字段名
  - 具体位置（行列号和Excel坐标）

### 日志管理功能

#### 1. 保存日志
- 点击"保存日志"按钮
- 选择保存位置和文件名
- 日志将以文本格式保存，格式清晰易读

**保存的日志文件格式：**
```
======================================================================
Excel字段提取 - 错误与警告日志
======================================================================

【错误日志】 共 X 条
----------------------------------------------------------------------
1. ❌ 错误信息...
2. ❌ 错误信息...

【警告日志】 共 X 条
----------------------------------------------------------------------
1. ⚠️ 警告信息...
2. ⚠️ 警告信息...

======================================================================
总计: X 个错误, X 个警告
```

#### 2. 清空结果
- 点击"清空结果"按钮
- 会同时清除提取结果和日志记录
- 为下一次提取做好准备

#### 3. 统计信息
- 窗口底部显示日志统计
- 格式：`总计: X 个错误, X 个警告`

## 💡 使用场景

### 场景1: 检查示例数据完整性
**问题：** 某些字段在 **`FIELD_TYPE_ROW`（默认第 6 行）** 的示例数据为空

**操作：**
1. 执行字段提取
2. 查看控制台输出或点击"错误日志"按钮
3. 在警告日志中查看哪些字段缺少示例数据
4. 根据位置信息（如"C6"）定位到Excel文件进行修复

**日志示例：**
```
⚠️ 示例数据为空 | 文件: game_config.xlsx | 工作表: 关卡配置 | 字段: level_desc | 位置: 第6行,第4列(D6)
```

### 场景2: 识别行数不足的表格
**问题：** 某些表格只有字段名，没有数据行

**操作：**
1. 执行字段提取
2. 查看警告日志
3. 找到"表格行数不足"的警告
4. 补充数据或调整表格结构

**日志示例：**
```
⚠️ 表格行数不足 | 文件: template.xlsx | 工作表: 新模板 | 字段: name | 当前行数: 5 (需要至少 FIELD_TYPE_ROW 行，默认 6)
```

### 场景3: 批量处理后的质量检查
**问题：** 处理了大量Excel文件，需要检查是否有问题

**操作：**
1. 批量提取完成后
2. 点击"错误日志"按钮
3. 查看统计信息（如"总计: 0 个错误, 15 个警告"）
4. 逐条检查警告，确定是否需要修复
5. 保存日志文件供团队其他成员查看

## 🔧 开发者接口

### Python API 使用

```python
from core.excel_field_extractor import ExcelFieldExtractor
from pathlib import Path

# 创建提取器
extractor = ExcelFieldExtractor()

# 执行提取
results = extractor.extract_fields_from_excel(Path("test.xlsx"))

# 获取日志
all_logs = extractor.get_all_logs()
errors = all_logs['errors']
warnings = all_logs['warnings']

print(f"错误数: {len(errors)}")
print(f"警告数: {len(warnings)}")

# 保存日志到文件
extractor.save_logs_to_file(Path("extraction_log.txt"))

# 清除日志
extractor.clear_logs()
```

### 可用方法

| 方法 | 说明 | 返回值 |
|------|------|--------|
| `get_error_logs()` | 获取错误日志 | `List[str]` |
| `get_warning_logs()` | 获取警告日志 | `List[str]` |
| `get_all_logs()` | 获取所有日志 | `Dict[str, List[str]]` |
| `clear_logs()` | 清除所有日志 | `None` |
| `save_logs_to_file(path)` | 保存日志到文件 | `bool` |

## 📊 日志信息详解

### 警告信息包含的字段

每条警告日志包含以下关键信息：

1. **⚠️ 警告类型**: 如"示例数据为空"、"表格行数不足"
2. **文件名**: 出现问题的Excel文件名
3. **工作表名**: 具体的工作表名称
4. **字段名**: 受影响的字段名
5. **位置信息**: Excel坐标（如"D6"）和行列号

### 定位问题的步骤

1. 查看日志中的"文件"字段 → 打开对应Excel文件
2. 查看"工作表"字段 → 切换到对应工作表
3. 查看"位置"字段 → 定位到具体单元格（如"D6"）
4. 修复问题
5. 重新运行提取
