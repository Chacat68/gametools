# 多语言翻译提取 - 界面布局说明

> **说明**：描述统一 GUI 中 **「多语言翻译提取」** 页（`gui/table_range_page.py`）与工作台的路径联动。完整流程见 [TABLE_RANGE_TRANSLATOR_GUIDE.md](TABLE_RANGE_TRANSLATOR_GUIDE.md)。  
> 策划表行约定见 [EXCEL_TABLE_LAYOUT.md](EXCEL_TABLE_LAYOUT.md)。

## 🖥️ 界面结构（示意）

```
┌────────────────────────────────────────────────────────────────────────────┐
│  侧栏：多语言提取  │  顶栏：路径请在「工作台」选择；本页只读显示并执行提取      │
├───────────────────┼──────────────────────────────────────────────────────────┤
│                   │  ┌─ 1. 合并 JSON 路径显示 ─────────────────────────────┐  │
│  工作台           │  │ JSON: [ D:\out\field_extraction_result_merged.json ]│  │
│  （路径源）       │  │ 检测到语言: ZH, VN, TH, EN                         │  │
│                   │  └────────────────────────────────────────────────────┘  │
│  主要流程         │  ┌─ 2. 语言目录显示 ───────────────────────────────────┐  │
│  · 字段导出       │  │ 中文:   [ D:\tables\zh\          ]                  │  │
│  · 多语言提取 ◀   │  │ 越南语: [ D:\tables\vn\          ]                  │  │
│  · 批量改表       │  │ 泰语:   [ D:\tables\th\          ]                  │  │
│                   │  │ 英语:   [ D:\tables\en\          ]                  │  │
│                   │  └────────────────────────────────────────────────────┘  │
│                   │  ┌─ 3. 输出与执行 ─────────────────────────────────────┐  │
│                   │  │ 输出目录: [ D:\out\trt\ ]（工作台选择，只读）         │  │
│                   │  │ [ 开始提取 ] [ 查看结果 ] [ 清空结果 ] [ 导出结果 ]   │  │
│                   │  └────────────────────────────────────────────────────┘  │
└───────────────────┴──────────────────────────────────────────────────────────┘
```

路径选择集中在 **「工作台」**；功能页文本框为只读，空路径显示「暂无」。

## 🎯 操作流程

```
开始
  │
  ├─> 1. 工作台：选择合并 JSON、zh/vn/th/en 目录、输出目录
  │
  ├─> 2. （可选）字段导出 → 「用于多语言提取」自动带入并跳转
  │
  ├─> 3. 多语言提取页：确认只读路径与 JSON 语言提示
  │
  ├─> 4. 开始提取 → 后台任务（TaskRunner）
  │
  └─> 5. 查看结果 / 导出 → 翻译总表 Excel（及可选 CSV）
```

## 📊 输出产物

默认在输出目录生成 **翻译总表**（单文件、多工作表，每表对应一个源 Excel）。列含字段名、ID、各语言文案等；CSV 导出时表头为 `ZH`、`VN`、`TH`、`EN`。详见 [TABLE_RANGE_TRANSLATOR_GUIDE.md](TABLE_RANGE_TRANSLATOR_GUIDE.md)「输出格式」。

## 🔧 主要操作

| 操作 | 说明 |
|------|------|
| 工作台选路径 | JSON、四语言目录、输出目录的唯一入口 |
| 开始提取 | 校验路径后启动 `TableRangeTranslator` |
| 查看结果 / 导出结果 | 通过 `ResultStore` 查看或保存最近一次任务输出 |
| 用于多语言提取 | 在字段导出页成功生成合并 JSON 后一键衔接 |

## 💡 使用技巧

1. **推荐顺序**：字段导出（JSON）→ 多语言提取 → 批量改表  
2. **语言目录**：与字段导出页共用工作台中的 zh/vn/th/en 路径变量  
3. **页签开关**：在「关于 → 界面与模块设置」中可隐藏本页（路径变量仍保留）
