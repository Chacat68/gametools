# v1.40.1 Bug修复报告

## 修复日期
2025-12-20

## 问题描述
用户在使用v1.40.0版本时，尝试使用翻译提取CSV文件（`系统翻译提取_20251219_165646_translated.csv`）作为批量改表的映射表时，遇到错误：

```
Excel file format cannot be determined, you must specify an engine manually.
```

## 问题原因
虽然v1.40.0版本已经添加了CSV格式支持，但在某些方法中仍然使用 `pd.ExcelFile()` 和 `pd.read_excel()` 读取映射表，没有先检查文件扩展名。这导致当映射表为CSV文件时，pandas尝试作为Excel文件读取而失败。

## 修复范围
以下方法已修复为完整支持CSV格式：

### 1. `process_batch_modification()` 方法
**位置**: `batch_excel_modifier.py` 第1259-1350行

**修复内容**:
- ✅ 获取工作表列表时检查文件扩展名
- ✅ CSV文件返回虚拟工作表名 `['CSV数据']`
- ✅ 自动检测语言列时使用 `load_mapping_table()` 读取CSV
- ✅ 读取工作表数据时使用 `load_mapping_table()` 并按Table列筛选

**修复前代码**:
```python
# 直接使用pd.ExcelFile
xl = pd.ExcelFile(mapping_path)
sheet_names = xl.sheet_names

# 直接使用pd.read_excel
df_sample = pd.read_excel(mapping_path, sheet_name=sheet, nrows=0)
df = pd.read_excel(mapping_path, sheet_name=sheet_name, header=0)
```

**修复后代码**:
```python
# 检查文件扩展名
file_ext = os.path.splitext(mapping_path)[1].lower()
if file_ext == '.csv':
    sheet_names = ['CSV数据']
    df_mapping = self.load_mapping_table(mapping_path)
    # ...处理CSV数据
else:
    xl = pd.ExcelFile(mapping_path)
    # ...处理Excel数据
```

### 2. `process_batch_modification_by_language()` 方法
**位置**: `batch_excel_modifier.py` 第1768-1950行

**修复内容**:
- ✅ 获取工作表列表时检查文件扩展名
- ✅ CSV文件返回 `['CSV数据']` 作为虚拟工作表
- ✅ 读取数据时使用 `load_mapping_table()` 方法

### 3. `get_mapping_file_languages()` 方法
**位置**: `batch_excel_modifier.py` 第1745-1790行

**修复内容**:
- ✅ 检查文件扩展名
- ✅ CSV使用 `pd.read_csv` 并支持多编码尝试
- ✅ 提取语言列时排除 `Table`, `Classification`, `ID` 列

## 改进亮点

1. **统一文件格式检查**: 所有读取映射表的方法都先检查文件扩展名
2. **智能格式转换**: CSV格式自动转换为批量改表所需格式
3. **按表筛选**: CSV包含多个表的数据，自动按Table列筛选
4. **保持向后兼容**: Excel文件处理逻辑完全保留

## 使用说明

现在可以直接使用翻译提取CSV文件作为批量改表的映射表：

1. 在多语言翻译提取功能中生成CSV文件
2. 在批量改表功能中选择该CSV文件作为映射表
3. 工具会自动识别格式并转换
4. 无需手动转换为Excel格式

## 已知限制

1. CSV文件不支持多工作表（本质限制）
2. CSV必须包含 `Table` 列来区分不同的表文件
3. 大文件（78K+行）加载约需1秒
