# 多语言翻译提取 - 多文件夹支持更新

## 更新日期
2025-11-20

## 功能说明

多语言翻译提取功能现已支持**多个独立文件夹**选择，可以同时从不同语言版本的文件夹中提取和对比翻译内容。

## 核心特性

### 1. 多语言文件夹支持
- ✅ **越南文目录**：默认无后缀（如 `config`）
- ✅ **中文目录**：带 `_zh` 后缀（如 `config_zh`）
- ✅ **泰文目录**：带 `_th` 后缀（如 `config_th`）

### 2. 智能语言识别
- 根据文件夹后缀自动识别语言类型
- 无后缀的文件夹默认为越南文版本
- 支持部分语言缺失（可以只选择1-2个语言）

### 3. 统一输出格式
生成的翻译总表包含所有语言版本的内容：
- 字段名
- 字段类型
- Excel位置（如 B7, C8）
- 中文内容
- 越南文
- 泰文

## 使用方法

### GUI界面

1. 启动 `gametools_v1.29.0.exe`
2. 选择"多语言翻译提取"标签页
3. 选择JSON配置文件（表字段导出工具生成）
4. **分别选择各语言目录**：
   - 越南文目录：`config` 或其他无后缀目录
   - 中文目录：`config_zh` 或其他带_zh后缀目录
   - 泰文目录：`config_th` 或其他带_th后缀目录
5. 选择输出文件位置
6. 点击"🚀 开始提取"
7. 查看翻译总表结果

**注意**：至少需要选择一个语言目录

### 文件夹结构示例

```
项目目录/
├── config/              # 越南文版本（无后缀）
│   ├── 角色配置.xlsx
│   ├── 物品配置.xlsx
│   └── 任务配置.xlsx
├── config_zh/           # 中文版本（_zh后缀）
│   ├── 角色配置.xlsx
│   ├── 物品配置.xlsx
│   └── 任务配置.xlsx
└── config_th/           # 泰文版本（_th后缀）
    ├── 角色配置.xlsx
    ├── 物品配置.xlsx
    └── 任务配置.xlsx
```

## 工作流程

```mermaid
graph LR
    A[JSON配置] --> B[提取器]
    C[越南文目录] --> B
    D[中文目录_zh] --> B
    E[泰文目录_th] --> B
    B --> F[数据合并]
    F --> G[翻译总表]
```

### 详细步骤

1. **读取JSON配置**
   - 获取需要处理的表格列表
   - 解析字段类型（只处理前端、后端、前后端）

2. **扫描各语言目录**
   - 从越南文目录读取 Excel 文件
   - 从中文目录读取对应的 Excel 文件
   - 从泰文目录读取对应的 Excel 文件

3. **提取并合并数据**
   - 以第一个可用语言为基准，定位字段列
   - 从各语言文件的相同位置提取内容
   - 记录 Excel 位置（如 B7, C8）

4. **生成翻译总表**
   - 每个表格文件对应一个工作表
   - 包含所有语言的内容
   - 便于对比和补充翻译

## 技术实现

### 核心方法

#### `process_with_json_config_multi_lang(json_path, lang_dirs)`
处理多语言目录的数据提取
- `lang_dirs`: 字典类型 `{'vn': 'path', 'zh': 'path', 'th': 'path'}`
- 返回：包含所有语言内容的数据列表

#### `generate_translation_master_table_multi_lang(output_path)`
生成多语言翻译总表
- 按表格名称分组
- 创建带样式的 Excel 工作簿
- 每个表格一个工作表

## 常见问题

### Q1: 必须提供所有三个语言目录吗？
**A**: 不需要，至少提供一个即可。其他语言列会显示为空。

### Q2: 文件夹后缀可以自定义吗？
**A**: 目前固定为 `_zh` 和 `_th`，无后缀默认为越南文。

### Q3: 如果某个语言的文件缺失怎么办？
**A**: 系统会自动跳过，不会影响其他语言的提取。

### Q4: Excel位置是什么格式？
**A**: 标准的Excel单元格引用，如 A1, B7, AB15 等。可以在Excel中按 Ctrl+G 直接跳转。

### Q5: 支持哪些字段类型？
**A**: 只导出"前端"、"后端"、"前后端"字段，自动跳过"策划"字段。
