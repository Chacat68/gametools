# Excel 数据处理（整合）- 使用说明

> 源文件与输出目录在 **「工作台」** 选择；「数据处理」页只读显示路径，并在本页配置整合选项。

## 功能概述

读取单个 Excel 源文件，按指定列（默认 A 列）分组，将各组写入输出文件的多个工作表（可配置工作表前缀、是否含汇总表）。底层逻辑：`tools/excel_data_processor.py` 的 `ExcelDataProcessor.process_file()`。

## 工作台路径

| 变量 | 说明 |
|------|------|
| Excel 整合源文件 | 待处理的 `.xlsx` / `.xls` |
| Excel 整合输出目录 | 结果文件所在目录 |

## 页内选项

| 选项 | 说明 |
|------|------|
| 输出文件名 | 默认 `整合结果.xlsx`，在本页填写 |
| 分组列 | 留空则按 A 列分组 |
| 工作表前缀 | 可选，写入各分组工作表名称 |
| 汇总工作表 | 勾选后在输出中附加统计汇总 |

## 操作步骤

1. 在 **「工作台」** 选择源文件与输出目录  
2. 打开 **数据处理** 页，填写输出文件名与选项  
3. 点击 **开始整合**  
4. 可用 **预览数据**、**查看结果** 核对输出

## 相关代码

- GUI：`gui/excel_data_processor_page.py`
- 核心：`tools/excel_data_processor.py`
- 测试：见 `tools/excel_data_processor.py` 内演示逻辑；GUI 冒烟见 `verify_gui.py`
