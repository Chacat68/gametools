# GameTools v1.26.0 版本更新说明

## 📅 发布日期：2025-01-22

## 🎯 核心更新：拆分输出格式

本次更新主要改进了**表字段导出工具**的输出格式，将结果分为两部分展示，让用户更清楚地了解哪些表格有本地化内容，哪些表格没有。

### ✨ 主要改进

#### 1. 📊 拆分输出逻辑
- **分类展示**：将结果分为【无文本内容的表格】和【有文本内容的表格】两部分
- **单独记录**：空表格不再被忽略，而是单独记录和展示
- **统计信息**：输出时显示空表格和非空表格的数量

#### 2. 📑 JSON 格式优化
```json
{
  "empty_tables": [
    {
      "table_name": "config.xlsx",
      "sheet_name": "配置表"
    }
  ],
  "tables_with_text": [
    {
      "table_name": "game_config.xlsx",
      "sheet_name": "关卡配置",
      "fields_with_examples": [
        "level_name,新手村",
        "level_desc,这是新手村的关卡"
      ],
      "field_count": 2
    }
  ]
}
```

#### 3. 📝 CSV 格式改进
- 使用醒目的分隔线区分两类表格
- 空表格显示在前，让用户快速识别
- 格式示例：
```
=== 无文本内容的表格 ===
config.xlsx#配置表

=== 有文本内容的表格 ===
game_config.xlsx#关卡配置,level_name,新手村,level_desc,简单关卡
```

#### 4. 📊 Excel 格式美化
- **橙色标题**：用醒目的橙色标题区分两个部分
- **灰色背景**：空表格使用灰色背景，一目了然
- **清晰布局**：两部分之间有空行分隔
- **视觉层次**：蓝色表头 + 不同背景色，层次分明

### 🔧 技术细节

#### 代码改进
1. **核心模块** (`core/excel_field_extractor.py`)
   - 新增 `empty_tables` 列表记录空表格
   - 修改 `extract_fields_from_excel` 方法，记录无文本内容的表格
   - 更新三个导出方法，支持拆分格式输出
   - 所有导出方法添加返回值，便于测试验证

2. **导出函数**
   - `export_to_json`: 返回 `output_file` 或 `None`
   - `export_to_csv`: 返回 `output_file` 或 `None`
   - `export_to_excel`: 返回 `output_file` 或 `None`

3. **文件路径处理**
   - 支持字符串和 Path 对象作为输入
   - 自动转换为 Path 对象进行处理
