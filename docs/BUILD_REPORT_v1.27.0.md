## 🎯 本次更新内容

### 表字段导出工具优化

#### 1. 标记检测优化
- **修改前**: 在第5行查找包含 `c_classic_battle` 的单元格
- **修改后**: 在第5行查找以 `c_` 开头的单元格
- **优势**: 更灵活的标记检测，支持所有 `c_` 开头的标记列

#### 2. 扫描范围调整
- **列范围限定**: 只扫描两个 `c_` 标记之间的列范围（不包含标记列本身）
- **精确提取**: 避免扫描不相关的列，提高准确性

#### 3. 移除全表扫描
- **修改前**: 未找到2个标记时，扫描整个工作表的所有列
- **修改后**: 未找到2个标记时，跳过该工作表并输出警告
- **好处**: 避免误提取不符合规范的表格

#### 4. 警告信息增强
- 当未找到2个 `c_` 标记时，输出清晰的警告信息：
  ```
  ⚠️ 未找到两个 c_ 标记，跳过工作表 | 文件: xxx.xlsx | 工作表: Sheet1
  ```

## 📋 更新后的规则

### 列范围扫描规则
1. **标记检测**: 在第5行查找 `c_` 标记（以 `c_` 开头的单元格）
2. **范围限定**: 如果找到至少2个标记，仅扫描两个标记之间的列（不包含标记列本身）
3. **跳过处理**: 如果未找到2个标记，跳过该工作表并输出警告

### 文本检测规则（保持不变）
- ✅ 包含: 中文、越南文、泰文字符
- ❌ 排除: 纯数字、空值、纯英文代码

### 字段提取规则（保持不变）
- **第5行**: 提取字段名
- **第6行**: 提取示例数据
- **第6行及之后**: 检测该列是否包含本地化文本
