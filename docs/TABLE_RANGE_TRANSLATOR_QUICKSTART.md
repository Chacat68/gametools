# 表范围翻译提取 - 快速开始

## 🚀 5分钟快速上手

### 第一步：生成JSON配置

1. 打开程序，选择"表字段导出"页签
2. 选择扫描目录（包含所有Excel文件）
3. 选择输出格式为"JSON格式"
4. 点击"开始提取"
5. 得到 `field_extraction_结果.json`

### 第二步：提取翻译内容

1. 切换到"表范围翻译提取"页签
2. 选择JSON配置（第一步生成的JSON文件）
3. 选择Excel目录（源Excel文件目录）
4. 选择输出文件（翻译总表保存位置）
5. 点击"开始提取"

### 第三步：查看结果

生成的翻译总表包含：
- 每个表格一个工作表标签
- 只包含前端、后端、前后端字段（策划字段已过滤）
- 列格式：字段名 | 字段类型 | ID | 行号 | 中文内容 | 越南文 | 泰文 | 语言类型

---

## 📝 示例

### 输入

**JSON配置**:
```json
{
  "text_tables": [
    {
      "table_name": "角色配置.xlsx",
      "fields_with_examples": [
        "id,策划",
        "name_cn,前端",
        "desc_cn,后端"
      ]
    }
  ]
}
```

### 输出

**翻译总表** (角色配置工作表):
| 字段名 | 字段类型 | ID | 行号 | 中文内容 | 越南文 | 泰文 | 语言类型 |
|--------|----------|-----|------|---------|--------|------|---------|
| name_cn | 前端 | 1001 | 7 | 张三 | | | 中文 |
| desc_cn | 后端 | 1001 | 7 | 普通角色 | | | 中文 |

*注意: id字段（策划类型）已自动跳过*

---

## ✨ 核心特性

- ✅ **自动过滤策划字段** - 只导出前端、后端、前后端
- ✅ **多语言识别** - 自动识别中文、越南文、泰文
- ✅ **按表分组** - 每个表格对应一个工作表
- ✅ **统一格式** - 标准化的翻译表格式
