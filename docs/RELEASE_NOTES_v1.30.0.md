## ✨ 新功能

### 多文件夹支持 - 多语言翻译提取增强

基于 v1.29.0 的多语言翻译提取功能，本版本新增**多文件夹选择**能力，支持从不同语言版本的独立文件夹中提取和对比翻译内容。

#### 核心特性

1. **多语言目录独立选择**
   - 越南文目录：无后缀文件夹（如 `config`）
   - 中文目录：`_zh` 后缀文件夹（如 `config_zh`）
   - 泰文目录：`_th` 后缀文件夹（如 `config_th`）

2. **灵活配置**
   - 至少选择 1 个语言目录即可运行
   - 支持 1-3 个语言目录任意组合
   - 自动跳过缺失的语言版本

3. **智能数据合并**
   - 从各语言文件夹的相同位置提取内容
   - 自动对齐同一字段的多语言内容
   - 统一输出到翻译总表

4. **统一展示格式**
   ```
   字段名 | 字段类型 | Excel位置 | 中文内容 | 越南文 | 泰文
   ```

## 📋 使用方法

### GUI界面操作

1. 启动 `gametools_v1.30.0.exe`
2. 选择"多语言翻译提取"标签页
3. 选择JSON配置文件（由表字段导出工具生成）
4. **分别选择各语言目录**：
   - 越南文目录：选择无后缀文件夹
   - 中文目录：选择 `_zh` 后缀文件夹
   - 泰文目录：选择 `_th` 后缀文件夹
5. 选择输出文件保存位置
6. 点击"🚀 开始提取"

## 🎯 使用场景

### 场景1：全语言对比
选择所有三个语言目录，一次性提取所有语言版本，便于对比和核对。

### 场景2：部分语言提取
只选择已有的语言目录（如只有中文和越南文），系统自动处理。

### 场景3：增量翻译
已有中文和越南文，新增泰文时，可以对比提取查漏补缺。

## 🔧 技术细节

### 新增API

#### `process_with_json_config_multi_lang(json_path, lang_dirs)`
处理多语言目录的数据提取
```python
lang_dirs = {
    'vn': 'path/to/config',
    'zh': 'path/to/config_zh',
    'th': 'path/to/config_th'
}
results = translator.process_with_json_config_multi_lang(json_path, lang_dirs)
```

#### `generate_translation_master_table_multi_lang(output_path)`
生成多语言翻译总表
```python
translator.generate_translation_master_table_multi_lang('翻译总表.xlsx')
```

## 🚀 其他功能

除了新增的多文件夹支持，本版本还包含 v1.29.0 的所有功能：

1. **越南文检测导出**：检测表格文件中的越南文并导出结果
2. **JSON错误检测工具**：检测JSON文件中的语法错误、结构错误、编码错误
3. **Excel数据处理工具**：根据A列内容对Excel数据进行分组和处理
4. **翻译提取**：批量提取Excel文件中的文本内容
5. **表字段导出**：生成JSON配置文件（作为多语言翻译提取的输入）
6. **多语言翻译提取**：基于JSON配置智能提取多语言翻译内容

## 💡 使用技巧

1. **文件夹命名规范**
   - 越南文版本：保持原始名称（如 `config`）
   - 中文版本：添加 `_zh` 后缀（如 `config_zh`）
   - 泰文版本：添加 `_th` 后缀（如 `config_th`）

2. **快速定位源文件**
   - 翻译总表中显示 Excel 位置（如 B7）
   - 打开源文件后按 Ctrl+G
   - 输入位置（B7）直接跳转

3. **批量处理工作流**
   ```
   表字段导出 → 生成JSON配置
        ↓
   多语言翻译提取 → 选择各语言目录
        ↓
   翻译总表生成 → 统一管理翻译
        ↓
   填充翻译内容 → 批量回填源文件
   ```

## ⚠️ 注意事项

1. 至少需要选择一个语言目录才能开始提取
2. Excel 文件名在各语言目录中必须保持一致
3. 建议在提取前备份重要文件
4. 文件夹后缀格式固定为 `_zh` 和 `_th`
