# 字段过滤功能 - 可视化说明

## 📊 功能流程图

```
Excel 表格输入
    ↓
┌─────────────────────────────────────┐
│  第5行: 字段名                       │
│  c_ | 序号 | des_cn | des_vcn | des │
│     | name | model  | id            │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│  内容检测（第6行及以后）             │
│  - 是否包含本地化文本？              │
│  - 中文、越南文、泰文？              │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│  字段名过滤 ⭐ 新功能                │
│  - name    → 过滤（代码标识符）      │
│  - model   → 过滤（数字ID）         │
│  - id      → 过滤（数据ID）         │
│  - des_cn  → 保留（中文文本）       │
│  - des_vcn → 保留（越南文文本）     │
│  - des     → 保留（越南文文本）     │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│  输出结果                            │
│  字段列表: des_cn, des_vcn, des     │
│  字段数量: 3                         │
└─────────────────────────────────────┘
```

### ❌ 过滤前的问题

```
提取结果: des_cn, des_vcn, des, name, model
         ^^^^^^^^^^^^^^^^^^^^^^^^  ^^^^^^^^^^^
         本地化文本字段              代码/数字字段
                                   ↓
                                  问题：
                                  - name 是资源标识符
                                  - model 是模型ID
                                  - 不应该被翻译
```

### ✅ 过滤后的结果

```
提取结果: des_cn, des_vcn, des
         ^^^^^^^^^^^^^^^^^^^^^^^^
         只保留本地化文本字段
         ↓
         优势：
         ✓ 准确性高
         ✓ 无噪音数据
         ✓ 翻译人员清晰明了
```

## 📋 过滤规则表

| 字段名  | 典型内容      | 判断依据        | 是否过滤 |
|---------|--------------|----------------|---------|
| name    | npc104_ui    | 代码标识符      | ✅ 是   |
| model   | 0, 1, 100    | 数字ID         | ✅ 是   |
| id      | 1001, 2002   | 唯一标识符      | ✅ 是   |
| code    | WEAPON_1     | 枚举值         | ✅ 是   |
| type    | 1, TYPE_A    | 类型标识       | ✅ 是   |
| des_cn  | 张若、黄蓉    | 中文文本       | ❌ 否   |
| des_vcn | Hoàng Dung   | 越南文文本     | ❌ 否   |
| des     | Tiểu Long Nữ | 越南文文本     | ❌ 否   |

## 🔧 技术实现

```python
# 简化版实现逻辑

# 1. 定义过滤规则
excluded_fields = {'name', 'model', 'id', 'code', 'type'}

# 2. 提取并过滤字段
for field_name in detected_fields:
    if field_name.lower() in excluded_fields:
        continue  # 跳过该字段
    result_fields.append(field_name)

# 3. 输出结果
# 只包含本地化文本字段
```
