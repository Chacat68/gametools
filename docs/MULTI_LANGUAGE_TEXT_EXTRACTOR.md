# 多语言文本提取工具使用说明

> **当前主流程**：统一 GUI 中的 **「多语言翻译提取」** 页（`gui/table_range_page.py`）。完整操作与输出格式请以 **[TABLE_RANGE_TRANSLATOR_GUIDE.md](TABLE_RANGE_TRANSLATOR_GUIDE.md)** 为准。  
> 下文保留多语言并行提取的概念说明；路径均在 **「工作台」** 选择，功能页只读显示。

> 策划表行号、列标记、行边界约定见 [EXCEL_TABLE_LAYOUT.md](EXCEL_TABLE_LAYOUT.md) 与 `core/constants.py`。

## 📋 功能概述

多语言翻译提取按字段导出生成的 **合并 JSON**，从各语言 Excel 目录抽取可交付的翻译总表（及可选 CSV）。支持语言与代码常量一致：**中文（zh）、越南语（vn）、泰语（th）、英语（en）**。

## ✨ 核心能力

### 1. 多语言目录

- **中文**：`zh` 表目录
- **越南语**：`vn` 表目录
- **泰语**：`th` 表目录
- **英语**：`en` 表目录

各语言目录在 **「工作台」** 配置；「多语言翻译提取」页只读显示。

### 2. 与字段导出衔接

1. 在 **字段导出** 页以 **JSON** 格式提取，生成合并配置（默认 `field_extraction_result_merged.json`）
2. 点击 **「用于多语言提取」** 带入路径并切换页签，或在工作台手动选择合并 JSON 与各语言目录

### 3. 输出

- 翻译总表 Excel（按源表分工作表）
- 可选 CSV（列：`ZH`、`VN`、`TH`、`EN` 等，见 `MERGED_JSON_LANGUAGE_KEYS`）

## 🎮 使用方法

### 启动

```bash
python gui/run_unified.py
```

侧栏选择 **「多语言翻译提取」**（或从字段导出页一键跳转）。

### 操作步骤

#### 步骤1：在工作台配置路径

1. **合并 JSON**：字段导出结果
2. **各语言 Excel 目录**：zh / vn / th / en
3. **输出目录**：翻译总表与 CSV 保存位置

#### 步骤2：在多语言提取页执行

1. 确认路径只读显示正确
2. 点击 **「开始提取」**
3. 在结果区查看进度；可用 **「查看结果」** / **「导出结果」**

详细字段筛选、行边界与输出列说明见 [TABLE_RANGE_TRANSLATOR_GUIDE.md](TABLE_RANGE_TRANSLATOR_GUIDE.md)。

## 📊 输出结构

翻译总表为单个 Excel（多工作表，每表对应一个源文件），列含字段名、ID、各语言文案等。若启用 CSV 导出，列头为 `ZH`、`VN`、`TH`、`EN`。详见 [TABLE_RANGE_TRANSLATOR_GUIDE.md](TABLE_RANGE_TRANSLATOR_GUIDE.md)「输出格式」。

## 💡 使用示例

### 示例：四语言并行提取

**场景**: 同时从 zh / vn / th / en 四个目录抽取翻译总表

**工作台配置**:

- 合并 JSON：`output/field_extraction_result_merged.json`
- 中文目录：`D:\项目\zh\`
- 越南语目录：`D:\项目\vn\`
- 泰语目录：`D:\项目\th\`
- 英语目录：`D:\项目\en\`
- 输出目录：`D:\提取结果\`

执行 **开始提取** 后，在输出目录生成翻译总表（及可选 CSV）。

## 🎯 应用场景

### 场景1: 多语言版本对比

提取所有语言版本的文本后，可以进行：
- 文本数量对比
- 翻译完整性检查
- 术语一致性验证

### 场景2: 翻译工作量评估

为每种语言提取文本后，可以：
- 统计各语言的文本总量
- 评估翻译工作量
- 制定翻译计划

### 场景3: 本地化质量保证

同时处理多个语言版本，便于：
- 检查翻译遗漏
- 发现格式问题
- 确保多语言同步

### 场景4: 增量更新处理

当游戏更新时：
- 只配置有更新的语言版本
- 快速提取新增或修改的文本
- 高效完成增量翻译

## 🔍 特殊说明

### 1. 策划行检测

- 若 Excel **`FIELD_TYPE_ROW`**（默认第 6 行）所在行包含「策划」相关规则触发跳过（与 `SKIP_FIELD_TYPE` 策略一致），将跳过整个文件的文本提取
- 行号与字段类型语义见 [EXCEL_TABLE_LAYOUT.md](EXCEL_TABLE_LAYOUT.md)

### 2. 文本提取规则

- 从 **`DATA_START_ROW`**（默认第 7 行）起检测数据区
- 同时提取 A 列内容作为 ID 关联
- **`FIELD_NAME_ROW`** 作为字段名行保留
- 数据区向下遇 **`ROW_BOUNDARY_KEYWORD`**（默认 `over`）即停止遍历
- 按合并 JSON 与各语言目录输出 **ZH / VN / TH / EN** 列（见 `MERGED_JSON_LANGUAGE_KEYS`）

### 3. 输出文件

- 默认生成 **翻译总表** Excel（多工作表，每表对应一个源 Excel）
- 可选导出 CSV，列头为 `ZH`、`VN`、`TH`、`EN` 等
- 输出路径由工作台「多语言输出目录」决定；覆盖策略以 GUI 提示为准

## ⚠️ 注意事项

1. **路径有效性**: 确保配置的路径存在且可访问
2. **磁盘空间**: 确保输出目录有足够的磁盘空间
3. **文件格式**: 仅支持`.xlsx`和`.xls`格式
4. **编码兼容**: 自动处理UTF-8、GBK等编码
5. **并发处理**: 按顺序处理每种语言，避免资源冲突
