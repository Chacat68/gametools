## ✨ 新功能

### 多语言翻译提取器
全新的翻译内容提取功能，基于JSON配置智能提取Excel表格中的翻译文本。

#### 核心特性

1. **智能字段过滤**
   - 只提取前端、后端、前后端字段
   - 自动跳过策划字段（减少噪音）
   - 基于JSON配置的`fields_with_examples`字段类型判断

2. **多语言支持**
   - 中文识别：U+4E00-U+9FFF
   - 越南文识别：U+00C0-U+1EF9
   - 泰文识别：U+0E00-U+0E7F
   - 混合语言智能检测

3. **Excel位置精确定位**
   - 输出Excel单元格引用格式（如 F8、C7、AB15）
   - 支持单字母列（A-Z）和多字母列（AA-ZZ、AAA...）
   - 便于快速定位到源文件具体位置（Ctrl+G直接跳转）

4. **简洁输出格式**
   - 字段名、字段类型、Excel位置
   - 中文内容、越南文、泰文
   - 删除冗余的ID和语言类型列

5. **翻译总表生成**
   - 按表格文件分工作表
   - 统一管理所有翻译内容
   - 支持批量翻译填充

## 📋 使用方法

### GUI使用

1. 启动 `gametools_v1.29.0.exe`
2. 选择"多语言翻译提取"标签页
3. 选择JSON配置文件（表字段导出工具生成的JSON）
4. 选择Excel文件所在目录
5. 设置输出文件路径
6. 点击"开始提取翻译"
7. 查看翻译总表结果

### 输入格式

**JSON配置文件结构**：
```json
{
  "no_text_tables": [...],
  "text_tables": [
    {
      "table_name": "角色配置.xlsx",
      "sheet_name": "角色列表",
      "fields_with_examples": [
        "name_cn,前端",
        "name_vn,前端",
        "desc_cn,后端",
        "config,策划"
      ]
    }
  ]
}
```

**Excel文件结构要求**：
- 第1-4行：说明信息（跳过）
- 第5行：字段名称
- 第6行：字段类型（前端/后端/前后端/策划）
- 第7行起：数据内容

### 输出格式

**翻译总表Excel结构**：

| 字段名 | 字段类型 | Excel位置 | 中文内容 | 越南文 | 泰文 |
|--------|----------|-----------|----------|--------|------|
| name_cn | 前端 | C7 | 张三 | | |
| name_cn | 前端 | C8 | 李四 | | |
| desc_cn | 后端 | F7 | 普通角色 | | |

## 🔧 技术细节

### 列字母转换算法
```python
def column_index_to_letter(col_idx: int) -> str:
    """0->A, 1->B, 25->Z, 26->AA, 27->AB..."""
    result = ""
    col_num = col_idx + 1
    while col_num > 0:
        col_num -= 1
        result = chr(col_num % 26 + ord('A')) + result
        col_num //= 26
    return result
```

### 处理流程
1. 加载JSON配置，获取`text_tables`列表
2. 跳过`no_text_tables`中的表格
3. 解析每个表格的字段类型
4. 过滤出可导出字段（前端/后端/前后端）
5. 从第7行开始提取数据
6. 检测语言类型（中文/越南文/泰文）
7. 生成Excel位置引用
8. 按表格分组输出到翻译总表

## 💡 使用技巧

1. **快速定位源文件**
   - 在翻译总表中看到"F8"
   - 打开源Excel文件
   - 按Ctrl+G，输入"F8"
   - 直接跳转到该单元格

2. **批量翻译工作流**
   - 使用表字段导出工具生成JSON配置
   - 使用多语言翻译提取所有需翻译内容
   - 在翻译总表中填充越南文和泰文
   - 按Excel位置回填到源文件

3. **字段类型管理**
   - 前端：UI显示文本
   - 后端：服务器配置数据
   - 前后端：双端共用数据
   - 策划：内部使用，自动跳过

## ⚠️ 注意事项

1. Excel文件必须遵循标准结构（第5行字段名，第6行字段类型）
2. JSON配置文件需先通过表字段导出工具生成
3. 大文件处理可能需要较长时间
4. 建议在提取前备份重要文件
