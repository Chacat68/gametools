# 批量改表功能 - 翻译提取CSV格式支持

## 🎉 新功能说明

批量改表功能现在可以**直接使用**翻译提取功能生成的CSV文件！无需手动转换格式。

## 📋 支持的CSV格式

### 格式1：标准批量改表格式（原有）
```csv
Table,Classification,ID,VN,TH,EN
armor_ancient.xlsx,des,1001,越南文描述,泰文描述,English Description
armor_ancient.xlsx,name,1001,越南文名称,泰文名称,English Name
```

### 格式2：翻译提取格式（新增支持）✨
```csv
Table,Sheet,Field,Type,Position,ZH,VN,TH,EN
amazing_book_open.xlsx,amazing_book_open,name,前端,B7,低级残卷,Tàn Quyển Cấp Thấp,เศษซากม้วนกระดาษระดับต่ำ
artifact.xlsx,artifact,desc,前端,H7,对敌方随机敌人造成绝对伤害,Tạo sát thương tuyệt đối,สร้างดาเมจสัมบูรณ์
```

## 🔄 自动格式转换

当加载翻译提取格式的CSV时，系统会自动进行以下转换：

| 翻译提取格式 | 转换为 | 批量改表格式 | 说明 |
|------------|--------|------------|------|
| `Table` | → | `Table` | 保持不变 |
| `Field` | → | `Classification` | 字段名作为分类 |
| `Position` (如B7) | → | `ID` (如7) | 提取行号作为ID |
| `VN/TH/EN` | → | `VN/TH/EN` | 语言列保持不变 |
| ~~`Sheet`~~ | 删除 | - | 不需要 |
| ~~`Type`~~ | 删除 | - | 不需要 |
| ~~`ZH`~~ | 删除 | - | 不需要（原文） |

## 🚀 使用方法

### 步骤1：生成翻译CSV
使用"多语言翻译提取"功能：
1. 选择Excel文件目录
2. 选择输出目录
3. 勾选"导出CSV格式"
4. 点击"开始提取"

生成文件如：`系统翻译提取_20251219_165646_translated.csv`

### 步骤2：直接用于批量改表
1. 打开"批量改表"页签
2. **映射表文件**：直接选择翻译提取生成的CSV文件 ✨
3. **JSON配置文件**：选择对应的JSON配置
4. **语言**：选择要修改的语言（如VN, TH）
5. **Excel目录**：选择要修改的Excel文件目录
6. 点击"开始修改"

### 步骤3：查看结果
系统会自动：
- 检测CSV格式类型
- 转换为批量改表格式
- 执行批量修改
- 生成修改报告

## ⚠️ 重要说明

### ID字段注意事项

翻译提取CSV中的`Position`列（如B7, E24）会被转换为行号作为ID：
- `B7` → ID = `7`
- `E24` → ID = `24`
- `H41` → ID = `41`

**这意味着**：
- ✅ 如果Excel文件的ID列恰好就是行号，直接可用
- ⚠️ 如果Excel文件的ID列是其他值（如1001, 2001），需要注意

**解决方案**：
1. **推荐**：确保JSON配置中的ID列定义正确
2. 或者：在翻译提取时确保Position对应正确的数据行
3. 或者：手动调整CSV中的ID列为实际ID值

### 支持的文件

- ✅ CSV文件（UTF-8, GBK, GB2312编码）
- ✅ Excel文件（.xlsx, .xls）
- ✅ 两种格式混用（同一项目中）

### 自动检测规则

系统通过以下条件判断是否为翻译提取格式：
- 存在`Position`列
- 存在`Field`列  
- 存在`Sheet`列

如果三个条件都满足，自动转换为批量改表格式。
