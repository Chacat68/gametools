# 多语言翻译提取器 - 功能说明

## 📋 功能概述

多语言翻译提取器是一个智能的多语言内容提取工具，根据字段导出的JSON配置文件，自动识别和提取Excel表格中需要翻译的内容，并生成统一的翻译总表。

### 核心特性

✅ **智能字段过滤**
- 根据JSON配置自动识别表格范围
- 只提取前端、后端、前后端字段
- 自动忽略策划专用字段
- 跳过no_text_tables中的表格

✅ **多语言识别**
- 支持中文、越南文、泰文、英文（拉丁字母）识别
- 自动分类语言类型（中文、越南文、泰文、英文、混合等）
- 纯数字与结构化占位仍会被过滤

✅ **翻译总表生成**
- 每个表格文件对应一个工作表标签
- 统一的列格式：字段名 | 字段类型 | ID | 行号 | 中文内容 | 越南文 | 泰文 | 英文 | 语言类型
- 美观的表格样式，带边框和冻结首行

## 🚀 使用方法

### 从字段导出接续（推荐）

1. 在 **字段导出** 页使用 **JSON** 格式完成一次提取，输出目录中会生成合并配置文件（默认文件名：`field_extraction_result_merged.json`，与常量 `FIELD_EXTRACTION_MERGED_JSON_NAME` 一致）。
2. 提取成功后，点击 **「用于多语言提取」**：程序会将合并 JSON 路径、各语言目录（与字段页填写一致）、输出目录写入 **多语言提取** 页，并自动切换页签、刷新 JSON 内语言检测提示。
3. 若未启用「多语言提取」页签，请在 **关于 → 界面与模块设置** 中开启后再使用衔接按钮。

### 1. 准备JSON配置文件

首先使用"表字段导出"功能生成JSON配置文件：

```json
{
  "no_text_tables": [
    {
      "table_name": "系统配置.xlsx",
      "sheet_name": "配置项"
    }
  ],
  "text_tables": [
    {
      "table_name": "角色配置.xlsx",
      "sheet_name": "角色列表",
      "fields_with_examples": [
        "id,策划",
        "name_cn,前端",
        "name_vn,前端",
        "desc_cn,后端"
      ],
      "field_count": 4
    }
  ]
}
```

### 2. GUI使用方式

#### 步骤一：打开程序
```bash
python gui/gametools_unified.py
```

#### 步骤二：选择"多语言翻译提取"页签

#### 步骤三：配置文件路径
1. **JSON配置**: 选择字段导出生成的JSON文件
2. **Excel目录**: 选择包含所有Excel表格的目录
3. **输出文件**: 选择翻译总表的保存位置

#### 步骤四：开始提取
点击"🚀 开始提取"按钮，程序将自动：
- 加载JSON配置
- 扫描Excel文件
- 过滤字段类型
- 提取文本内容
- 生成翻译总表

### 3. 命令行使用方式

```bash
python core/table_range_translator.py <JSON配置文件> <Excel目录> --output <输出文件>
```

**示例**:
```bash
python core/table_range_translator.py field_config.json excel_files/ --output 翻译总表.xlsx
```

说明：`--output` 对应的 Excel 文件属于运行时导出产物，文件名和保存位置都可以自定义；示例中的 `翻译总表.xlsx` 只是演示名称。

## 📊 输出格式

### 翻译总表结构

生成的 Excel 文件包含多个工作表，每个工作表对应一个源表格文件。下面以 `翻译总表.xlsx` 为示例文件名：

```
翻译总表.xlsx
├── 角色配置 (工作表)
│   ├── 字段名
│   ├── 字段类型
│   ├── ID
│   ├── 行号
│   ├── 中文内容
│   ├── 越南文
│   ├── 泰文
│   └── 语言类型
├── 物品配置 (工作表)
└── 任务配置 (工作表)
```

### 列说明

| 列名 | 说明 | 示例 |
|------|------|------|
| **字段名** | Excel中的字段名称 | name_cn, desc_cn |
| **字段类型** | 字段用途分类 | 前端, 后端, 前后端 |
| **ID** | 对应行的A列ID值 | 1001, 2001 |
| **行号** | Excel中的物理行号 | 7, 8, 9 |
| **中文内容** | 提取的中文文本 | 张三, 宝剑 |
| **越南文** | 待填充的越南文翻译 | （空白） |
| **泰文** | 待填充的泰文翻译 | （空白） |
| **英文** | 待填充的英文翻译 | （空白） |
| **语言类型** | 自动识别的语言类型 | 中文, 越南文, 泰文, 英文 |

## 🎯 工作流程

### 完整工作流

```mermaid
graph LR
    A[Excel源文件] --> B[表字段导出]
    B --> C[JSON配置]
    C --> D[多语言翻译提取]
    D --> E[翻译总表]
    E --> F[翻译团队]
    F --> G[填充翻译]
    G --> H[导入回源文件]
```

### 详细步骤

1. **字段分析阶段**
   - 使用"表字段导出"扫描所有Excel文件
   - 生成JSON配置文件
   - 标记字段类型（前端/后端/前后端/策划）

2. **内容提取阶段**
   - 加载JSON配置
   - 跳过no_text_tables
   - 处理text_tables
   - 过滤策划字段
   - 提取文本内容

3. **总表生成阶段**
   - 按表格分组数据
   - 创建工作表标签
   - 应用格式样式
   - 保存输出文件

## ⚙️ 配置说明

### 字段类型分类

| 字段类型 | 说明 | 是否导出 |
|---------|------|---------|
| **策划** | 策划专用，不需要翻译 | ❌ 跳过 |
| **前端** | 客户端显示，需要翻译 | ✅ 导出 |
| **后端** | 服务器使用，需要翻译 | ✅ 导出 |
| **前后端** | 前后端共用，需要翻译 | ✅ 导出 |

### 语言类型识别

| 语言类型 | 字符范围 | 示例 |
|---------|---------|------|
| **中文** | U+4E00–U+9FFF | 张三, 宝剑 |
| **越南文** | U+00C0–U+1EF9 | Tiểu Tam, Kiếm |
| **泰文** | U+0E00–U+0E7F | จางซาน, คำ |
| **中越混合** | 同时包含中文和越南文 | 张三Tiểu |
| **中泰混合** | 同时包含中文和泰文 | 张三จาง |

## 🔍 处理报告

提取完成后，会生成详细的处理报告：

```
======================================================================
多语言翻译提取处理报告
======================================================================
总表格数: 3
已处理: 3
已跳过: 0

总字段数: 0
已导出字段: 10
已跳过字段（策划）: 5

提取数据行数: 25
======================================================================
```

### 报告字段说明

- **总表格数**: JSON配置中text_tables的数量
- **已处理**: 成功提取的表格数量
- **已跳过**: 无法处理的表格数量
- **已导出字段**: 实际导出的字段数量
- **已跳过字段**: 被过滤的策划字段数量
- **提取数据行数**: 总共提取的文本行数

## ⚠️ 注意事项

### Excel表格要求

1. **标准格式**
   - 第5行必须是字段名行
   - 第6行必须是字段类型行
   - 第7行开始是数据内容

2. **字段类型标记**
   - 必须使用标准类型: 策划、前端、后端、前后端
   - 类型错误或缺失会导致字段被跳过

3. **列范围标记**
   - 使用c_标记列范围（可选）
   - 未标记则处理所有列

### 文件路径

- JSON配置文件路径必须正确
- Excel目录必须包含所有配置中的文件
- 文件名必须与JSON配置中完全匹配

### 性能考虑

- 大文件处理可能需要较长时间
- 建议先测试小范围数据
- 确保足够的内存空间

## 🔧 故障排除

### 问题1: 字段未找到

**原因**: 字段名在第5行不匹配  
**解决**: 检查Excel第5行字段名是否正确

### 问题2: 数据行不足

**原因**: Excel数据少于7行  
**解决**: 确保至少有第7行数据

### 问题3: 没有提取到数据

**原因**: 所有字段都是策划类型  
**解决**: 检查第6行字段类型标注

### 问题4: JSON配置错误

**原因**: JSON格式不正确  
**解决**: 使用JSON验证工具检查格式
