# GameTools 版本历史归档

本文档记录 v1.30.0 之前的历史版本更新记录。文中「第 5/6/7 行」等与当前代码常量 **`FIELD_NAME_ROW` / `FIELD_TYPE_ROW` / `DATA_START_ROW`** 对应，详见 [EXCEL_TABLE_LAYOUT.md](EXCEL_TABLE_LAYOUT.md)。

## v1.29.0 (2025-11-20)
- ✨ 新功能：多语言翻译提取器
- 📊 智能字段过滤：只提取前端、后端、前后端字段，自动跳过策划字段
- 🌐 多语言支持：中文、越南文、泰文内容智能识别
- 📍 Excel位置定位：输出Excel单元格引用（如F8）而非简单行号
- 🎯 简洁输出：删除ID和语言类型列，专注翻译核心信息
- 📋 翻译总表：按表格分工作表，统一管理所有翻译内容

## v1.28.0 (2025-11-20)
- 🔧 字段类型提取：从第6行提取字段类型（策划、前端、后端、前后端）
- 📊 JSON格式优化：fields_with_examples从'字段名,示例值'改为'字段名,字段类型'
- ⚠️ 警告信息更新：字段类型为空时生成警告
- ✅ 保持扫描逻辑：仅修改输出内容，扫描范围和规则不变

## v1.27.x 系列 (2025-11-20)
- 📏 检测行调整：多语言文本检测从物理行第7行开始
- 🗑️ 精简启动方式：移除独立GUI和命令行工具
- ✨ 字段过滤：自动过滤 name、model、id、code、type 等代码字段
- 🎯 标记优化：表字段导出标记从 c_classic_battle 改为 c_

## v1.26.0 (2025-11-19)
- 📋 分区输出：无文本表与有文本表分离展示
- 📊 JSON重构：增加no_text_tables、text_tables分区和summary统计

## v1.25.x 系列 (2025-11-19)
- 📊 表字段导出工具v2.0：扫描Excel文件提取字段信息
- 🎯 JSON格式输出：标准化数据结构
- 📝 错误日志：添加提取失败的检测和日志记录功能
- 🎯 列范围限制：表字段导出锁定在两个 c_ 标记之间
- 📊 字段+示例：输出格式添加第6行的前端示例数据

## v1.24.0 (2025-01-15)
- ⚙️ 配置管理：集中化配置系统，支持持久化和导入/导出
- 🎮 任务控制：暂停/恢复/取消长时间任务
- 📊 进度增强：子步骤跟踪、改进的ETA计算
- 🔍 结果过滤：支持10种过滤操作符
- 📄 多格式输出：支持6种格式

## v1.23.0 (2025-11-14)

- 🧠 智能缓存：实现LRU淘汰策略，支持内存大小限制

## v1.22.0 (2025-11-13)
