# gametools v1.40.0 发布说明

## 🎉 重大更新

批量改表功能现在可以**直接使用**翻译提取生成的CSV文件！

## 📦 版本信息

- **版本号**: v1.40.0
- **发布日期**: 2025年12月20日
- **文件大小**: 44.43 MB

## ✨ 新增功能

### 🔄 翻译提取CSV格式无缝集成

批量改表功能新增对翻译提取CSV格式的直接支持：

**之前的工作流**：
```
翻译提取 → 生成CSV → ❌需要手动转换格式 → 批量改表
```

**现在的工作流**：
```
翻译提取 → 生成CSV → ✅直接使用 → 批量改表 🎉
```

### 核心特性

1. **自动格式检测** 🔍
   - 自动识别翻译提取CSV格式
   - 检测标准批量改表格式
   - 无需手动指定格式类型

2. **智能格式转换** 🔄
   - Position列（B7, E24）→ 自动提取行号作为ID
   - Field列 → Classification分类
   - 自动移除不需要的列（Sheet, Type, ZH）
   - 保留语言列（VN, TH, EN等）

3. **高性能处理** ⚡
   - 支持78000+行大文件
   - 加载时间 <1秒
   - 转换时间 <0.2秒

## 📊 格式对比

### 翻译提取格式（输入）
```csv
Table,Sheet,Field,Type,Position,ZH,VN,TH
artifact.xlsx,artifact,name,前端,B7,打狗棒,Xuyên Long Thương,หอกทะลวงมังกร
artifact.xlsx,artifact,desc,前端,H7,对敌方造成伤害,Tạo sát thương,สร้างดาเมจ
```

### 批量改表格式（自动转换后）
```csv
Table,Classification,ID,VN,TH
artifact.xlsx,name,7,Xuyên Long Thương,หอกทะลวงมังกร
artifact.xlsx,desc,7,Tạo sát thương,สร้างดาเมจ
```

## 🚀 使用方法

### 快速开始

1. **翻译提取**
   - 使用"多语言翻译提取"功能
   - 勾选"导出CSV格式"
   - 生成：`系统翻译提取_xxx_translated.csv`

2. **批量改表**（新方式）
   - 映射表文件：**直接选择**翻译提取生成的CSV ✨
   - JSON配置：选择对应配置文件
   - 语言：选择要修改的语言
   - Excel目录：选择目标文件夹
   - 点击"开始修改"

3. **自动处理**
   - 系统自动检测格式
   - 自动转换为批量改表格式
   - 执行批量修改
   - 生成修改报告

## ⚠️ 注意事项

### ID字段说明

翻译提取CSV中的`Position`列会被转换为行号：
- `B7` → ID = `7`
- `E24` → ID = `24`
- `H41` → ID = `41`

**适用场景**：
- ✅ Excel文件的ID列就是行号
- ✅ 通过JSON配置指定正确的ID列
- ⚠️ 如果ID是特殊值（如1001），需要确认配置

### 编码支持

- UTF-8（推荐）
- GBK
- GB2312
- UTF-8-sig（带BOM）
