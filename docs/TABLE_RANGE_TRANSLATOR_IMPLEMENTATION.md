## 🎯 功能特点

### 智能过滤

| 字段类型 | 处理方式 |
|---------|---------|
| 策划 | ❌ 跳过（不导出）|
| 前端 | ✅ 导出 |
| 后端 | ✅ 导出 |
| 前后端 | ✅ 导出 |

### 多语言支持

| 语言 | 字符范围 | 识别状态 |
|------|---------|---------|
| 中文 | U+4E00–U+9FFF | ✅ 支持 |
| 越南文 | U+00C0–U+1EF9 | ✅ 支持 |
| 泰文 | U+0E00–U+0E7F | ✅ 支持 |
| 混合 | 多种组合 | ✅ 支持 |

### 输出格式

```
翻译总表.xlsx
├── 角色配置 (工作表)
│   ├── 字段名
│   ├── 字段类型
│   ├── ID
│   ├── 行号
│   ├── 中文内容
│   ├── 越南文
│   ├── 泰文
│   └── 语言类型
├── 物品配置 (工作表)
└── 任务配置 (工作表)
```
