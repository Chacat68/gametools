## 🔄 主要变更详解

### 1. 数据提取位置

#### v1.27.2
```
行5: 字段名     → des_cn, des_vcn, des_en
行7: 示例数据   → 张若, Tiểu Long Nữ, Little Dragon Girl

#### v1.28.0
```

**输出**: `["des_cn,策划", "des_vcn,前端", "des_en,后端"]`

## 🎓 最佳实践

### Excel表格设计

推荐的标准表格结构：

```
行1: 表说明
行2-4: 预留空间
行5: 字段名 (des_cn, des_vcn, des_en)
行6: 字段类型 (策划, 前端, 后端)
行7+: 实际数据
```

### 字段类型规范

| 类型 | 使用场景 | 示例字段 |
|------|----------|----------|
| **策划** | 策划编辑，不导出 | 备注、说明 |
| **前端** | 客户端显示 | UI文本、图标路径 |
| **后端** | 服务器逻辑 | 配置参数、计算公式 |
| **前后端** | 前后端共用 | ID、类型、名称 |

## 💬 常见问题

### Q1: 两个版本可以共存吗？
**A**: 可以。两个版本是独立的exe文件，可以同时保留。

### Q2: 如何同时获得示例值和字段类型？
**A**: 可以：
- 使用 v1.27.2 导出示例值
- 使用 v1.28.0 导出字段类型
- 手动合并两份结果

### Q3: 原有的CSV和Excel输出受影响吗？
**A**: v1.28.0 目前只修改了JSON格式，CSV和Excel格式保持不变。

### Q4: 可以自定义字段类型吗？
**A**: 可以。第6行可以填写任何文本作为字段类型，不限于"策划、前端、后端、前后端"。
