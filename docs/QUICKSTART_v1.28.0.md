## 📋 Excel表格要求

### 标准表格结构

```
行号 | 列A | 列B    | 列C     | 列D    | 列E  | 列F   | 列G
-----|-----|--------|---------|--------|------|-------|-----
1-4  |     | 说明   |         |        |      |       |
5    | c_  | des_cn | des_vcn | des_en | name | model | c_
6    |     | 策划   | 前端    | 后端   |前后端| 策划  |
7+   | 1   | 张若   | Tiểu L. | Little |npc_01| 0     |
```

### 关键行说明

| 行号 | 用途 | 必需 |
|------|------|------|
| **第5行** | 字段名 | ✅ 必需 |
| **第6行** | 字段类型 | ✅ 必需（新功能）|
| **第7行+** | 数据内容 | ✅ 必需 |

---

## 🔧 字段类型说明

在第6行填写字段类型：

| 类型 | 说明 |
|------|------|
| **策划** | 策划专用，不导出 |
| **前端** | 前端客户端使用 |
| **后端** | 后端服务器使用 |
| **前后端** | 前后端共用 |

## ⚠️ 常见问题

### Q: 第6行为空怎么办？
**A**: 会生成警告，输出为 `"字段名,"`

### Q: 必须有 c_ 标记吗？
**A**: 是的，必须有两个 `c_` 标记才会扫描该工作表

### Q: 支持哪些语言？
**A**: 中文、越南文、泰文
